# Illustrazioni dei pasti

Sei illustrazioni originali generate con `image_gen`: colazione, metà mattina,
pranzo, merenda, cena e un piatto neutro per i pasti personalizzati.
PNG 192 × 192 con trasparenza, 281676 byte complessivi; palette verde bosco,
salvia e lime coordinata con peppitness. Prompt completi in [prompts.json](prompts.json).

Le immagini identificano il momento del pasto: gli ingredienti illustrati sono
decorativi. Alimenti e quantità visualizzati provengono esclusivamente dal piano.
`MealImage` sceglie l'immagine dal nome e, in assenza di un nome riconoscibile,
dall'orario. Non introduce categorie o dosi nei dati salvati.

Originali conservati nella cartella generated_images di Codex; esportazione
ridotta senza alterare il contenuto. Riscontri in docs/DIET_CARDS_RESULT.md.
